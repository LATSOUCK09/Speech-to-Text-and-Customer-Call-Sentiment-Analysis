# Speech-to-Text and Customer Call Sentiment Analysis

Cette application propose une démo Gradio pour :
- transcrire un appel audio,
- analyser le sentiment du texte,
- afficher la transcription et les probabilités de sentiment.

## Déploiement sur Hugging Face Spaces

1. Créez un nouveau Space Hugging Face avec la template Gradio.
2. Uploadez ce dépôt ou connectez votre dépôt GitHub.
3. Définissez le point d'entrée sur `app.py`.
4. Assurez-vous que les dépendances sont listées dans `requirements.txt`.

## Lancement local

```bash
python app.py
```
